# 요약 파이프라인 변천

글마다 "요약할 가치가 있나" 를 고르는 1차와, 고른 글을 요약하는 2차가 어떻게 바뀌어 왔는지를 한 표로 적었다. 측정이 없는 칸은 "기록 없음" 으로 둔다 - 그때 재지 않은 것을 나중에 지어내지 않기 위해서다. 버전은 웹앱 변경 기록의 버전이다.

## 이 표에서 읽을 것

- **측정이 붙은 결정은 07 월 뒤부터다.** 1~5 월의 결정(분류기 도입, 단일 호출, 재분리)에는 남은 측정이 없다. 그 시기 숫자를 나중에 만들어 넣지 않았다.
- **스스로 틀린 것을 지우지 않았다.** 예고한 rho 0.49, Gemma 한도 14,400(실제 1,440), 분류기 합격선 FAIL 을 그대로 둔다.
- **"불가능" 기록을 다시 쟀다.** thinking 끄기는 같은 조건으로 재현한 뒤에야 뒤집었다.
